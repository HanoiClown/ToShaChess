# Security

ToShaChess is a local family training app. Profiles separate progress; they are not authenticated accounts and do not protect one Windows user from another. Keep backups private. API keys are encrypted using Windows secure storage and omitted from JSON backups; re-enter a key after moving computers.

Do not post keys, personal database files or private game archives in public issues. For suspected vulnerabilities, use the repository's private vulnerability reporting feature if the maintainer has enabled it. Otherwise request a private contact without publishing exploit details or credentials. No dedicated response-time commitment is provided.

The optional API budget is local to this installation. It does not include spending by other applications or synchronize across computers. Offline play and analysis do not need a key.
